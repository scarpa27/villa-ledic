# Apartments Ledić

I created this website as a favor for a friend. Built with React and Bootstrap.

[View the live website](https://front3.edukacija.online/aledic/villa-ledic/)

## Run locally

Copy `.env.example` to `.env` and update the settings, then run:

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://127.0.0.1:3000).

## Build

```sh
npm run build
```

The files for deployment are generated in `build/`.
